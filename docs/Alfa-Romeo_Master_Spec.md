# Альфа-Ромео — банк 2035
### Полная продуктовая и техническая спецификация · v2 (master spec для Claude Code + основа презентации)

---

## 0. Как пользоваться этим документом

Единый источник правды по концепту. Два назначения:

1. **Для Claude Code** — раздаёшь по волнам (см. §14). Каждый экран/сервис описан так, чтобы из него собрать промпт.
2. **Для презентации** — §2 (исследования), §3 (идеи), §9 (карта экранов) + §4–8 (новые продукты) закрывают бриф.

**Концепт:** мы показываем не «near-future», а **банк 2035 года** — финансовая операционная система, где у человека один паспорт (KYC) и сколько угодно профилей: личный, бизнес, семейный, детский; где рубли, цифровой рубль и крипта — одни деньги; где есть свой мобильный оператор; и где ИИ — не чат-бот, а второй пилот. Регуляторика 2026 (см. §2.4) — это «как мир пришёл к нашему 2035»; в демо она служит нарративом, а не ограничением.

**Что нового в v2 (по сравнению с v1):** тарифы/классы (§4), мультиаккаунт и переключение профилей (§5), заказ карт + виртуальные/несколько карт/доставка (§6), мобильный оператор Ромео Mobile (§7), **Ромео-Бизнес** (§8).

Стек: **iOS (SwiftUI)** основной, бэкенд отдельным сервисом, web — стретч. Поддержка/ИИ — через Anthropic API (ключ на бэке, §11.7).

## 1. Позиционирование

**Альфа-Ромео — финансовая ОС 2035 года: один человек → много профилей, одни деньги (₽ + цифровой ₽ + крипта), свой мобильный оператор и ИИ-второй-пилот.**

Опоры, отличающие нас от банка «здесь и сейчас»:

| Опора | Что это |
|---|---|
| **AI-native** | Claude-копилот сквозной: поддержка + проактивный финкоуч + агентные действия с подтверждением |
| **Crypto-fiat как единые деньги** | Крипто, рубли, цифровой рубль в одном кошельке. Мгновенная конвертация, переводы крипты контакту по номеру |
| **One identity → many profiles** | Личный / бизнес / семейный / детский профили под одним KYC, переключение в один тап |
| **Membership-модель** | Тарифы Base/Pro/Infinite — кэшбек, лимиты крипты, AI, мобильный пакет растут с классом |
| **Свой оператор (MVNO)** | Ромео Mobile: eSIM, тариф вшит в класс, кэшбек гигабайтами, оплата ГБ/роуминга хоть криптой |
| **Ромео-Бизнес** | Полноценный банк для бизнеса в том же приложении: РКО, эквайринг, зарплаты, роли, бизнес-AI |

**Строка для слайда:** *«Один аккаунт на всю жизнь — личные финансы, бизнес, связь и крипта в одной ОС, где ИИ работает за тебя».*

## 2. Исследование (база для презентации)

Структура под бриф: клиентский опыт + рынок → тренды → идеи (§3) → дизайн экранов (§9). Факты ниже — реальные данные 2025–2026, на них строится правдоподобие «дороги к 2035».

### 2.1. Тренды финтеха (что станет нормой к 2035)
- **Super-app / единый хаб.** Баланс, крипта, платежи, страховка, связь, бизнес — в одном месте; сложное прячут в горизонтальные скролл-хабы.
- **End-to-end биометрия.** Не только вход — подтверждение операций, крупных переводов, рекуррентных платежей через Face ID / отпечаток / голос. Пароль — резерв.
- **AI из «по расписанию» в «реального времени».** Адаптивные ИИ-поверхности, реагирующие на контекст; персонализация — флагман.
- **Embedded everything.** Инвестиции, страховки, кэшбек, бюджет, связь, бизнес-сервисы — встроены.
- **Crypto-fiat рельсы.** Стейблкоины из спекуляции в платёжный инструмент; крипто-карты, мгновенные конвертации, переводы по чейнам.
- **Membership-экономика.** Подписочные тиры (Revolut Standard/Premium/Ultra, T-Bank Pro/Premium) — главный драйвер выручки и удержания.
- **Финтех-MVNO.** Банки запускают своих операторов (Тинькофф Мобайл, Альфа): eSIM, тариф в связке с банком, кэшбек минутами/ГБ.
- **Геймификация и микровзаимодействия.** Анимации статусов, прогресс целей, «выгода как игра».
- **Предсказуемость под нагрузкой.** Прозрачные статусы/откаты операций, прогрессивное раскрытие данных, кросс-платформенная согласованность.

### 2.2. Клиентский опыт и рынок РФ
- **Альфа уже глубоко в ИИ.** «Альфа-Ассистенты» (советы, инструкции, планы) на GigaChat; внутри — умный поиск, no-code конструктор ИИ-агентов (H2 2026), Deep Research (лето 2026). Вывод: ИИ-копилот ложится в ДНК Альфы, но мы идём дальше — агентность + сквозной слой.
- **Membership работает.** На скринах Альфы — подписка **«Альфа-Смарт»** (бандл: +1 категория кэшбека, бесплатные переводы). Наш Base/Pro/Infinite — развитие этой модели.
- **Финтех-MVNO — доказанная модель.** Тинькофф Мобайл и Альфа уже продают связь в связке с банком; кэшбек гигабайтами, eSIM, управление в банковском приложении.
- **Спрос на крипту огромен.** ~20 млн россиян, ~50 млрд ₽ операций/день; сейчас серая зона через P2P (блокировки по 115-ФЗ). Легальный банковский крипто-сервис закрывает массовую боль.
- **Бизнес-банкинг — отдельный большой рынок.** T-Bank Бизнес / Альфа Бизнес: РКО, эквайринг, зарплатные проекты, бухгалтерия, роли. Ромео-Бизнес — наш ответ в той же ОС.

### 2.3. Крипто-нейробанки как референс (Revolut, Plasma One)
Что переносим: покупка/продажа 200+ активов; отправка крипты между аккаунтами мгновенно и бесплатно, в т.ч. контактам; депозит/вывод 30+ монет во внешние кошельки; конвертация стейблкоинов 1:1 мультичейн; крипто-карта (конвертация в фиат «под капотом» при оплате); стейкинг и трейдинг в приложении. Под капотом: кастоди/кошельки, провайдеры ликвидности, on/off-ramp, ноды, KYC/AML; доход — спреды, интерчейндж, **подписки** (отсюда важность тиров, §4).

### 2.4. Регуляторная рамка (нарратив «как пришли к 2035»)
Кратко — для слайда «почему в 2035 это легально и нормально»:
- 2026 — крипто-сервисы **начинают интегрироваться в банковскую систему**; закон определяет работу банков с криптоактивами.
- Квал-инвестор: порог 24 млн ₽ (с 01.01.2026); неквал — лимит 300 тыс ₽/год через посредника + тест на риски.
- ЦБ цель — закон об инвестициях в крипту в 2026 + трансграничные расчёты через **ЭПР**.
- Допущены BTC/ETH + стейблы; анонимные монеты (Monero/Zcash) — запрет для лицензированных площадок.
- **Цифровой рубль** — массовое внедрение с 01.09.2026, двухуровневая модель (ЦБ — платформа, банк — интерфейс).

**В демо:** комплаенс зашит в UX мягко (статус инвестора, лимиты, BTC/ETH+стейблы, цифровой рубль нативно). Это превращает риск в дифференциатор, но не доминирует над «вау».

## 3. Ключевые продуктовые идеи

Раздел «ключевые идеи по развитию» из брифа. Каждая — на основе трендов/исследований.

1. **Claude-копилот как сквозной слой** — поддержка 24/7 с контекстом операций; проактивный финкоуч; агентные действия по команде с подтверждением+биометрией. Гардрейлы §11.7.
2. **Единый мультивалютный кошелёк** — ₽ + цифровой ₽ + крипта на одном экране, единый ₽-эквивалент.
3. **Мгновенная конвертация крипто↔₽ и крипто-переводы контактам по номеру** — получатель видит сумму в ₽, конвертация под капотом.
4. **Крипто-карта** — платишь криптой, мерчанту приходит фиат.
5. **Стейкинг как «вклад нового поколения»** — рублёвые вклады и крипто-стейкинг в одном хабе, честное сравнение рисков.
6. **AI-аналитика бюджета** — автокатегоризация, прогноз, аномалии, цели, объяснимые инсайты.
7. **Кредиты с explainable AI-преквалификацией** — преодобрение в реальном времени с объяснением и симулятором.
8. **Геймификация выгоды** — выбор категорий кэшбека, супер-кэшбек, серии/цели (без тёмных паттернов).
9. **🆕 Membership-тиры (Base/Pro/Infinite)** — единая ось, по которой растут кэшбек, лимиты крипты, AI, мобильный пакет, поддержка (§4).
10. **🆕 One identity → many profiles** — личный/бизнес/семейный/детский профили под одним KYC, переключение в один тап (§5).
11. **🆕 Заказ карт за секунды** — виртуальная мгновенно (сразу в Apple Pay), пластик опционально с доставкой и трекингом; несколько карт, одноразовые виртуалки для онлайна (§6).
12. **🆕 Свой оператор Ромео Mobile** — eSIM, тариф в связке с классом, кэшбек гигабайтами, оплата связи/роуминга криптой (§7).
13. **🆕 Ромео-Бизнес** — банк для бизнеса в той же ОС: РКО, эквайринг, зарплаты, роли, бизнес-AI (§8).

## 4. Membership: тарифы и классы 🆕

**Модель:** один бесплатный базовый + платные подписки. Тир — глобальная ось привилегий: кэшбек, лимиты/спреды крипты, AI, мобильный пакет, поддержка, тревел. Названия — плейсхолдеры, можно переименовать к питчу.

### 4.1. Личные тиры

| | **Ромео Base** | **Ромео Pro** | **Ромео Infinite** |
|---|---|---|---|
| Цена | бесплатно, без подписки | подписка ₽/мес | подписка ₽₽₽/мес (топ) |
| Кэшбек | базовый, 1 категория | повышенный, +1–2 категории, супер-кэшбек | максимальный, выбор всех категорий, премиум-партнёры |
| Карты | 1 виртуальная | до 3 (вирт+пластик) | без лимита + металл/крипто-карта |
| AI-копилот | базовый (лимит запросов/день) | расширенный (без лимита, финкоуч) | премиум (проактивный + агентный приоритет) |
| Крипта | просмотр + малые лимиты, обычный спред | сниженный спред, выше лимиты | минимальный спред, премиум-стейкинг APY, повышенные лимиты |
| Переводы | СБП бесплатно, межбанк/за рубеж — комиссия | бесплатные за рубеж + крипто-переводы | всё бесплатно, приоритетное исполнение |
| Ромео Mobile | пакет S (базовые ГБ) | пакет M (больше ГБ + роуминг) | безлимит + роуминг включён |
| Поддержка | стандарт (AI + очередь) | приоритет | консьерж 24/7, выделенная линия |
| Тревел/лайфстайл | — | скидки у партнёров | лаунж-доступ, страховка путешествий, консьерж |

**Логика для Claude Code:** тир — это **feature flags + лимиты** на бэке (`Subscription.tier`), а не отдельные экраны. Везде в UI спорные функции читают тир и либо доступны, либо показывают «апселл-карточку» (мягко, без тёмных паттернов).

### 4.2. Бизнес-тиры (для Ромео-Бизнес, §8)
- **Бизнес Старт** — бесплатно: 1 счёт, базовый эквайринг (QR/линк), 1 пользователь, базовый бизнес-AI.
- **Бизнес Pro** — подписка: мультивалютные счета (вкл. крипто-трежери), полный эквайринг, зарплатный проект, роли/команда, расширенный AI (счета, прогноз кэшфлоу).
- **Бизнес Корп** — топ: повышенные лимиты, мульти-юрлица, приоритетные выплаты, API/интеграции, агентный бизнес-AI, выделенная поддержка.

### 4.3. Сценарии
- **Апгрейд/даунгрейд:** экран «Подписка» → сравнение тиров → оплата → мгновенная активация привилегий; даунгрейд с конца оплаченного периода.
- **Апселл-точки:** на крипто-конвертации («Pro: спред ниже»), на 2-й карте («Pro: до 3 карт»), на лимите неквал («повысить статус»), в Mobile («Infinite: безлимит»). Всегда отклоняемо, не навязчиво.
- **Триал:** 1 месяц Pro новым пользователям (демо-нарратив).

## 5. Мультиаккаунт и переключение профилей 🆕

**Принцип:** один человек проходит KYC один раз → создаёт несколько **профилей** под одной личностью. Профиль = изолированные счета/карты/лимиты/тир, но общая верификация.

### 5.1. Типы профилей
- **Личный** — дефолтный.
- **Бизнес** — ИП/ООО/самозанятый (открывает Ромео-Бизнес, §8). Можно несколько (мульти-юрлица на Корп).
- **Семейный/совместный** — общий бюджет с «Близкими» (как в Альфе), общий счёт/цели.
- **Детский** — привязан к родителю, родительский контроль (лимиты, категории, геозоны), детская карта.

### 5.2. Переключатель профилей (UX)
- Тап по аватару (как в Альфе) → шторка со списком профилей → переключение в один тап.
- **Цветовая маркировка контекста:** личный — фирменный акцент; бизнес — графит; детский — мягкий цвет. Пользователь всегда видит, «где он».
- При переключении в бизнес — опциональный повторный биометрический unlock (настраивается).
- Бейдж непрочитанных/задач на иконке профиля.
- «+ Добавить профиль» → бизнес-онбординг / семейный / детский.

### 5.3. Бэкенд-модель
- `Profile` (тип, тир, тема) ← привязан к `User` (KYC). `Membership` (роль/права user→profile, нужно для бизнеса и совместных).
- Все денежные сущности (Account, Card, Transaction…) scoped по `profile_id`.
- Сессия знает активный `profile_id`; API-запросы — в его контексте.

## 6. Карты: заказ, виртуальные, несколько, доставка 🆕

### 6.1. Типы карт
- **Виртуальная** — выпуск мгновенно, сразу в Apple Pay / Alfa-Pay-стикер.
- **Пластиковая** — заказ с доставкой (Base/Pro/Infinite дизайны).
- **Крипто-карта** — списание крипты, мерчанту фиат (§ идея 4).
- **Одноразовая виртуальная (burner)** — для онлайна/подписок: single-merchant lock или single-use номер, мгновенная генерация и сжигание. Сильный «2035»-штрих к безопасности.

### 6.2. Флоу заказа (ключевой)
1. «Заказать карту» → выбор типа (дебет/кредит/крипто/одноразовая).
2. Выбор дизайна/тира (см. §13.2) + к какому счёту/крипто-активу привязать.
3. **Виртуальная выпускается сразу** → доступна для оплат немедленно (показ реквизитов под «глазом», добавление в кошелёк).
4. Опционально: «Заказать пластик» → адрес (карта/геолокация) → способ (курьер/почта/в отделении) → стоимость по тиру → подтверждение.
5. **Трекинг доставки**: статусы `оформлена → печать → в пути → доставлена` (анимированный, как статусы операций) → активация по прибытии (NFC/код).

### 6.3. Несколько карт и управление
- Лимит карт по тиру (Base 1 / Pro 3 / Infinite ∞).
- Список карт на дашборде (карусель), выбор «карты по умолчанию».
- По каждой: заморозка/разморозка, лимиты, реквизиты (глаз), смена PIN, перевыпуск, смена дизайна, привязка к счёту/крипто-активу, добавление в Apple Pay.
- Одноразовые: создать «под покупку» → авто-сжигание после транзакции / лимит мерчанта.

### 6.4. Бэкенд
- `Cards` сервис: пайплайн выпуска (вирт мгновенно), токенизация PAN, генерация одноразовых VCN, мок-логистика доставки (статусы/трекинг), лимиты/заморозка. `CardOrder` хранит статус физической карты и адрес.

## 7. Ромео Mobile — мобильный оператор (MVNO) 🆕

**Идея:** собственный виртуальный оператор в связке с банком. eSIM по умолчанию (2035 — возможно iSIM), тариф вшит в класс, кэшбек гигабайтами, оплата связи с любого счёта (вкл. крипту).

### 7.1. Возможности
- **Мгновенный eSIM**: активация по QR прямо в приложении; новый номер или перенос (MNP).
- **Тариф в связке с тиром** (§4.1): Base→S, Pro→M (+роуминг), Infinite→безлимит.
- **Кэшбек гигабайтами/минутами**: траты по карте → ГБ; или крипто-кэшбек за мобильные платежи.
- **Роуминг 2035**: включён на Infinite; «оплатить роуминг криптой/стейблами» в путешествии.
- **Семейный шеринг** ГБ с профилями «Близкие»/детский.
- **Управление**: остатки ГБ/минут, детализация, смена тарифа, вторая eSIM, блокировка/замена.

### 7.2. Экраны
`Mobile-хаб` (остатки, тариф, кэшбек) · `Подключение eSIM` (QR/новый/MNP) · `Тарифы` (связка с тиром) · `Детализация/использование` · `Роуминг` · `Семейный пакет` · `Оплата связи` (любой счёт/крипта).

### 7.3. Бэкенд
- `Mobile/MVNO` сервис: мок-интеграция с «оператором» (provisioning eSIM, учёт ГБ/минут, тарифы), привязка `MobilePlan` к `user/profile`, метеринг использования, начисление кэшбека.

## 8. Ромео-Бизнес 🆕

**Полноценный банк для бизнеса в той же ОС.** Открывается как бизнес-профиль (§5), переключение в один тап. Своя навигация (бизнес-режим), своя тема (графит), свои тиры (§4.2).

### 8.1. Онбординг бизнеса
ИП/ООО/самозанятый → ввод ОГРН/ИНН (или подтягивание из реестра) → проверка → роли учредителей → согласия → выпуск бизнес-счёта (мгновенно, «2035»).

### 8.2. Модули (бизнес-навигация)
- **Дашборд** — баланс по счетам, кэшфлоу, задачи (счета на оплату/подписи), AI-инсайт.
- **Счета/РКО** — рублёвые + мультивалютные + **крипто-трежери** (стейблкоины как операционная валюта), выписки.
- **Эквайринг** — онлайн (линки/интернет-эквайринг), офлайн (QR/NFC/терминал), **крипто-эквайринг** (приём стейблов с авто-конвертацией в ₽), отчёты по выручке.
- **Зарплаты** — зарплатный проект, массовые выплаты на карты/самозанятым/в крипту, реестры.
- **Контрагенты и счета** — платежи по реквизитам, справочник контрагентов, выставление/оплата счетов (invoices), документооборот.
- **Команда и роли** — пользователи с ролями `владелец / бухгалтер / менеджер`, права, **многоступенчатое подтверждение** (2-of-N подпись для крупных платежей).
- **Корпоративные карты** — виртуальные/пластик на сотрудников, лимиты, управление расходами.
- **Аналитика** — кэшфлоу, P&L, прогноз **кассового разрыва**, налоги.
- **Бизнес-AI (Claude)** — генерация счетов, проверка контрагента, прогноз кэшфлоу, помощник по налогам/отчётности, черновики документов, **агент**: оплата поставщикам с подтверждением, ответы на отзывы, контент-план (как «Нейроофис» Альфы, но агентный).
- **Интеграции/API** — маркетплейсы, бухгалтерия (1С-класс), вебхуки.

### 8.3. Сценарии (ключевые)
- **Принять оплату:** создать линк/QR → клиент платит (карта/СБП/цифр.₽/крипта) → авто-конвертация крипты в ₽ → зачисление + чек.
- **Заплатить поставщику:** счёт/реквизиты → если сумма > лимита → отправляется на подпись второму лицу → биометрия → исполнение.
- **Выплатить зарплату:** реестр → проверка → массовая выплата → статусы по каждому.
- **Спросить бизнес-AI:** «сделай счёт на 120 000 ₽ для ООО Ромашка» / «когда кассовый разрыв?» → карточка-действие → подтверждение.

### 8.4. Бэкенд
- `Business` сервис: юрлица, счета/РКО, контрагенты, инвойсы, зарплатные реестры, точки эквайринга. `Membership`/роли для команды и подписей. Переиспользует `Payments`, `Cards`, `Crypto`, `AI-orchestration`, `Pricing`.

## 10. Детальные флоу (ключевые)

### 10.1. Онбординг/аутентификация
Регистрация: телефон→OTP→KYC (паспорт+ИНН / **Госуслуги OAuth**)→**liveness-селфи**→согласия→PIN→Face ID+**passkey**. Вход: дефолт Face ID; фолбэк PIN/OTP. Новое устройство: подтверждение со старого/звонок+binding. Edge: офлайн-кэш read-only, отказ биометрии→PIN, backoff OTP, блок после N. Anti-fraud: device fingerprint, поведенческие сигналы, подтверждение крупных операций биометрией.

### 10.2. Главный
AI-инсайт строкой → продуктовые карточки → офферы → Mobile → «На карте». Персонализация порядка (ML). Состояния: пустой (онбординг-карточки «Открыть карту/кошелёк»), скелетоны, ошибка+кэш. Единый ₽-эквивалент в шапке.

### 10.3. Переводы/платежи
СБП по телефону; **крипто-перевод контакту** (актив→сумма в ₽/крипте по live-курсу→превью комиссии сети→биометрия→статус; получателю без кошелька — инвайт+авто-создание); **цифровой рубль** (универсальный QR / C2C, кошелёк цифр.₽ как отдельный счёт); за рубеж (+крипто/стейбл-рельса через ЭПР в нарративе). Edge: недостаточно средств, лимиты, превышение лимита неквал, откат с прозрачным статусом.

### 10.4. Карты
См. §6. Виртуальная мгновенно → опционально пластик с доставкой/трекингом → активация. Несколько карт, одноразовые для онлайна, управление (заморозка/лимиты/реквизиты/дизайн/привязка).

### 10.5. Кредиты
Витрина с преодобренными суммами → **explainable преквалификация** (факторы решения + симулятор) → оформление (сумма/срок→график→согласия→биометрия→статус). Edge: отказ с причиной+«что улучшить», частичное одобрение.

### 10.6. Накопления (вклады+стейкинг)
Хаб «Приумножить»: рублёвые вклады (ставка/срок/капитализация) и крипто-стейкинг (APY/lock/риск) рядом, честное раскрытие (АСВ vs рыночный риск). Цели с прогрессом и авто-пополнением. Стейкинг-флоу: актив→сумма→lock→обяз. чекбокс риска→подтверждение.

### 10.7. История/аналитика
Лента (как реф) + аналитика (диаграмма/категории/%/помесячно) + **AI** (автокатегоризация, прогноз к концу месяца, аномалии «подписки +40%», цели, «спросить AI про операцию»). Ручной учёт, экспорт PDF/CSV.

### 10.8. Крипто-модуль
Дашборд (live), покупка/продажа (сумма→превью курс/спред/комиссия→биометрия→исполнение), конвертация (крипто↔₽ мгновенно, ↔стейбл 1:1), отправка/приём (контакт/адрес/QR/сеть), стейкинг. **Комплаенс в UX:** статус инвестора, тест на риски (gate), лимит-прогресс, BTC/ETH+стейблы, запрет анонимных. Edge: re-quote с TTL при волатильности, перегрузка сети, превышение лимита.

### 10.9. AI-поддержка/копилот (Claude)
Каналы: вкладка «Чаты» + плавающая кнопка + контекстные точки (на операции/отказе). Режимы: *Поддержка* (RAG+контекст, эскалация), *Финкоуч* (проактив с разрешения), *Агент* (tool-use: перевод/вклад/заморозка — ВСЕГДА подтверждение+биометрия). UX: стриминг (SSE), карточки-действий, источники, «человеку» в тап. Гардрейлы §11.7.

### 10.10. 🆕 Тиры/мультиаккаунт/Mobile/Бизнес
Апгрейд тира (сравнение→оплата→активация флагов). Переключение профиля (шторка→тап→опц. биометрия, смена темы/таб-бара). eSIM (QR→активация→тариф по тиру). Бизнес: онбординг→РКО→эквайринг (линк/QR→оплата→авто-конвертация крипты)→платёж поставщику с многоступенчатой подписью→зарплатный реестр→бизнес-AI с карточками-действий.

### 11.4. Live-цены на крипту
- Портфель/оценка ₽: **CoinGecko REST** (широкое покрытие, free demo, обновление 30–60 с, кэш в Redis).
- Live-тикер/графики: **Binance WebSocket** (быстрые spot-стримы) / **CoinCap WS** (бесплатно). WS не считается в REST-лимиты; на 429 — exp. backoff; чередование источников.
- Курс ₽: крипта в USD → конвертация в ₽ на бэке (CBR/рыночный) для консистентного единого эквивалента.
- Исполнение: демо — симуляция по live-цене + спред (спред зависит от тира, §4); продакшн — лицензированный провайдер ликвидности/биржа (будущий реестр ЦБ).

### 11.5. Крипто-кастоди/исполнение
Демо: внутренний ledger + симулятор кошельков/ордеров по реальным ценам. Продакшн: кастодиан (HSM/MPC), on/off-ramp, ноды/инфра (Infura-класс) для депозитов/отправки.

### 11.6. Цифровой рубль
Двухуровневая модель (ЦБ — платформа, банк — интерфейс). Кошелёк цифр.₽ = отдельный счёт (открыть/перевести/оплатить, универсальный QR). Демо — мок-интеграция с реалистичным UX.

### 11.7. AI-оркестрация (Anthropic) — «поддержка как Claude»
Ключ **только на бэке**. Контекст: профиль (активный!) + последние операции + RAG-база → системный промпт с минимизацией PII. **Tool-use:** `get_balance`, `make_transfer`, `open_deposit`, `freeze_card`, `convert_crypto`, `create_invoice` (бизнес), `pay_supplier` (бизнес), `explain_transaction`, `search_kb`. Финансовые инструменты возвращают «черновик действия» → клиент показывает карточку → **биометрия** → бэк исполняет. AI сам деньги не двигает. Стриминг SSE. Гардрейлы: скоупы по действию **и по роли/тиру**, лимиты сумм для агентных операций, отказ вне домена, полный аудит-лог, фильтр PII, эскалация на человека. Модель — под задачу (быстрая для FAQ, сильная для коуча/агента).

### 11.8. Безопасность/комплаенс
Биометрия+passkeys, токенизация PAN, секреты в KMS/Vault, TLS, подпись транзакций, **многоступенчатые подписи для бизнеса**. KYC/AML «цифровой контроль» для крипты, мониторинг подозрительных операций (115-ФЗ), лимиты неквал, запрет анонимных монет. Audit trail по всем финансовым и AI-действиям. Изоляция данных по `profile_id` + проверка `Membership` на каждом запросе.

### 11.9. Realtime
WS: цены/балансы/статусы. SSE: AI-стриминг. Push: silent wake + локальная сборка (приватность).

## 13. Дизайн-система и карты для демо

### 13.1. Визуальный язык — «future premium 2035»
**Токены** (как на Vertex MMA): color / type / spacing / radius / motion. Палитра: наследие красного как акцент + футуристичная база (графит/near-black, белый), один электрический акцент; **крипто/AI** — холодный градиент (визуально отделяет от фиата); **бизнес** — графитовая тема (контекст профиля). **Тёмная тема — первичная.** Типографика: сильный гротеск (заголовки) + нейтральный (текст) + моно (суммы/курсы/адреса). Иконки/иллюстрации — глянцевые 3D (как у Альфы, узнаваемо и «дорого»). Motion: анимированные статусы операций/доставки карт, прогресс целей/лимитов/ГБ, плавные переходы — сдержанно.

### 13.2. Физические демо-карты (нужен дизайн)
Линейка под тиры:
- **Base** — матовый графит, минимализм, монограмма «A», `··последние4`, NFC, МИР.
- **Pro** — насыщеннее, акцент-кант, премиальная фактура.
- **Infinite** — металл/тёмный с акцентом, тиснение, «бесконечность».
- **Crypto Card** — отдельная айдентика (холодный градиент/прозрачный слой), бейдж крипто, тот же платёжный контур.
- **Бизнес/корп** — графит, лого юрлица, поле «сотрудник».

## 14. Дорожная карта реализации в Claude Code

Под твой workflow (параллельные волны по непересекающимся файлам; последовательно — где конфликт).

- **Фаза 0 — фундамент** *(послед.):* дизайн-токены, навигационная оболочка (таб-бар + роутинг + **режим профиля**), Auth/KYC, **Identity/Profiles + переключатель**, базовый API-клиент + WS/SSE-слой, **Subscriptions/Tiers (фичефлаги)**.
- **Фаза 1 — ядро личного** *(парал.):* Главный/дашборд · Карты (детейл+управление+**заказ/виртуальная/доставка**) · Переводы/Платежи · История/лента.
- **Фаза 2 — продукты+крипта** *(парал.):* Крипто-модуль + Pricing (live-цены) · Накопления (вклады+стейкинг) · Аналитика бюджета · **Ромео Mobile (MVNO)**.
- **Фаза 3 — AI:** AI-оркестрация на бэке (tool-use, RAG, гардрейлы, скоупы по роли/тиру) → клиентский копилот/поддержка (стриминг, карточки-действий).
- **Фаза 4 — Ромео-Бизнес:** бизнес-режим (онбординг, дашборд, счета/РКО, эквайринг, команда/роли+подписи, корп-карты, бизнес-AI) — **focused MVP** (см. §15).
- **Фаза 5 — web + полировка:** web (если время), микровзаимодействия, пустые/ошибочные состояния, демо-данные.

**Что мокать vs строить:** реальные — live-цены, AI-копилот, UX всех флоу, тиры/профили/заказ карт. Мок/симуляция — крипто-исполнение/кастоди, цифр.₽, KYC-провайдер, банковские рельсы, оператор связи, логистика доставки.

## 15. Решения для демо (приняты, поправь если что)

1. **Бизнес = режим в одном приложении, не отдельное приложение.** Под твоё «можно менять аккаунты» — переключатель профилей (личный↔бизнес↔семейный↔детский). Проще для демо, цельная ОС, один логин. *(Если захочешь отдельное приложение — это лишняя сборка; не советую к дедлайну.)*
2. **Ромео-Бизнес — focused MVP, а не полный ERP.** Честно: полноценный бизнес-банк (бухгалтерия, налоги, 1С, тендеры) к дедлайну не построить. Для «вау» хватит: бизнес-онбординг + дашборд + счета/РКО + эквайринг (линк/QR с авто-конвертацией крипты) + команда/роли с многоступенчатой подписью + бизнес-AI. Остальное — заглушки/слайды.
3. **Тиры — 3 личных (Base/Pro/Infinite) + 3 бизнес (Старт/Pro/Корп).** Реализуются как фичефлаги+лимиты, а не отдельные экраны. Названия/цены — плейсхолдеры, финализируешь к питчу.
4. **MVNO/цифровой рубль/доставка карт — симуляция** с реалистичным UX. Для «банка 2035» это честно и снимает блокеры.
5. **Регуляторика — нарратив, не ограничение.** Комплаенс зашит в UX мягко (статус инвестора, лимиты, BTC/ETH+стейблы); на питче — слайд «как мир пришёл к 2035».
6. **Название «Альфа-Ромео».** Для демо ок (премиальная «итальянская/быстрая» ассоциация). На публичной защите подай осознанно как игру слов (Alfa Romeo — живой автобренд Stellantis), чтобы не читалось как недосмотр.
